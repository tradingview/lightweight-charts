Inverted price scale

Price scales

A price scale flipped so that higher values are at the bottom.

Interactive example — scroll, zoom, and hover the chart.

How it works​

A price scale normally grows from bottom to top. Inverted, it grows from top to bottom, so higher values are drawn lower.

To flip the scale, set invertScale: true in the price scale options. The example sets it on the right price scale, which the series uses; the line is highlighted in the code.

Tips​

  • The option can be set for one scale with chart.priceScale('right').applyOptions({ invertScale: true }).
