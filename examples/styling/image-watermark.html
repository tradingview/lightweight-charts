Image watermark

Styling

An image watermark drawn behind the series.

tip

For more control than the built-in watermark gives, use the Image watermark plugin. It can anchor the image to a corner, fill the pane, or draw it behind one series instead of the whole pane. You can also replace the image after it is added.

Interactive example — scroll, zoom, and hover the chart.

How it works​

An image watermark is a picture drawn behind the series in a pane.

  1. createImageWatermark adds the image to the first pane, from panes. The options set its opacity and padding.
  2. The image here is embedded in the code as a data URL. Usually it is the URL of an image file.

The call is highlighted in the code.

Tips​

  • The image in this example is black on a transparent background, so it is hard to see in dark mode. Use an image that works on both backgrounds, or switch it with the theme.
  • createImageWatermark centers the image and scales it to fit. To place it any other way, use the plugin from the tip above.
