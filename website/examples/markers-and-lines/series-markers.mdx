## How it works

A series marker is a shape with optional text attached to a data point, for example to show a trade or an event.

1. The markers are built as an array. Each has a `time`, a `position` (above, below, or in the bar), a `shape`, a `color`, and optional `text`. The vertical position comes from the data point, so no price is needed.
2. [`createSeriesMarkers`](/docs/api/functions/createSeriesMarkers) attaches the markers to the series.

The markers are highlighted in the code.

## Tips

- `createSeriesMarkers` returns an object whose `setMarkers` replaces the markers later, and `setMarkers([])` removes them all.
