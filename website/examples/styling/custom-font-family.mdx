## How it works

All the text on the chart, on the scales and in labels, uses one font family from the layout options.

The buttons call `setFontFamily`, which passes the chosen font to [`applyOptions`](/docs/api/interfaces/IChartApi#applyoptions) as `layout.fontFamily`. The chart starts with the first font in the list. The call is highlighted in the code.

## Tips

- Load a web font before the chart is created, or call `applyOptions` again once it has loaded. Otherwise the chart draws with a fallback font.
