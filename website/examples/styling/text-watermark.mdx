## How it works

A text watermark is one or more lines of text drawn behind the series in a pane.

[`createTextWatermark`](/docs/api/functions/createTextWatermark) adds the watermark to the first pane, from [`panes`](/docs/api/interfaces/IChartApi#panes). The options set its alignment and, for each line, the text, color, and font size. The call is highlighted in the code.

## Tips

- The function returns the watermark. Call its `applyOptions` to change the text later.
- For an image instead of text, see [Image watermark](./image-watermark.mdx).
